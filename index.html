Case Study: SpySee

A live attendance platform used by frontline staff — from problem framing through production deployment.

The Problem

Manual attendance for frontline teams was slow, error-prone, and gave managers no real-time visibility into who was actually on site. Sign-in queues ate into productive time and reports were compiled by hand.

The Approach

As Tech Lead & Scrum Master, I ran sprint planning, broke the build into shippable slices, and owned the attendance logic — the core clock-in/out engine that determines presence, lateness, and shift completion. I also QA'd each release and coordinated the live deployment.

The Outcome

A live, production-deployed web app with sub-2-second QR sign-in, live onsite dashboards for admins, and Google Sheets sync for reporting. Deployed to lcstudio-incubate.co.za alongside teammate Dominic Peck using FileZilla.

My Role

  • Tech Lead — architecture & code review
  • Scrum Master — sprint planning & standups
  • Attendance logic — core sign-in engine
  • QA testing — release validation
  • Live deployment — FileZilla with Dominic Peck
